AUGUR

A Chain Oracle that reads public wallets and produces plain-English statements. Read-only. Public data only. No wallet connection. No keys. No custody.

read-only public data only no wallet connection no keys no custody early build
This page is an early landing. The product is being built in public. The first demo is a clean statement page and a waitlist.

What it does

  • You paste a public wallet address
  • AUGUR reads public history
  • AUGUR produces clean statements you can act on
No connect button. No signing. No seed phrases. No private keys.

What it is not

  • Not a wallet
  • Not a custody service
  • Not a trading tool
  • Not a data vacuum
You stay in control. AUGUR stays read-only.
