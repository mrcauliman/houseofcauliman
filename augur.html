AUGUR

A simple way to turn public wallet activity into clear, plain-English statements. Add public addresses and labels. AUGUR reads public data and organizes it into something normal humans can understand.

Public data only No wallet connection No keys No custody
Join the waitlist View repo

What it does

  • Statement view for each address
  • Inflows, outflows, fees, net change
  • Token and NFT inventory deltas
  • Exports you can save and share

What you do

1
Add an address and a label
2
Run a snapshot
3
Read the statement output
You can do this for one wallet or fifty

What you never do

  • No connect wallet button
  • No seed phrases
  • No private keys
  • No custody at any point

Why this exists

Most people can read a bank statement. Almost nobody wants to dig through explorer pages and raw transaction noise. AUGUR turns ledger activity into a readable statement so you can make decisions fast.

MVP scope

  • Add public address with label
  • Snapshot now and snapshot monthly
  • Statement view with totals and deltas
  • Export JSON plus simple statement text
