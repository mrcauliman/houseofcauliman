AUGUR operator runbook

Command set to install the AUGUR CLI, run the local API, manage accounts, produce snapshots, produce monthly summaries, and export outputs.

read-only public data only no wallet connection no keys no custody

Get into the box and the right folders

If you see mrcauliman@mrcauliman:~$, you are at your home directory. Use these to land in the right place fast.

# confirm who and where whoami pwd hostname # House site repo (AUGUR landing page) cd /var/www/houseofcauliman.com # AUGUR app repo (API + CLI) cd /var/www/augur
If a cd fails, the folder path is wrong or the repo is not present on that machine. Run ls -la /var/www to confirm what exists.

Install the AUGUR CLI

This installs /usr/local/bin/augur from the repo copy.

cd /var/www/augur || exit 1 chmod +x scripts/install_augur_cli.sh bash scripts/install_augur_cli.sh command -v augur augur status
If you edited cli/augur, re-run the installer so /usr/local/bin/augur matches.

API control

Run the API on port 8787.

# start in background augur api:bg # verify health curl -sS http://127.0.0.1:8787/health ; echo curl -sS http://127.0.0.1:8787/api/health ; echo # tail logs augur api:logs # stop augur api:stop
If foreground API fails with EADDRINUSE, stop the background API first using augur api:stop.

Accounts

List, add, pause, resume, delete. All account operations are read-only to wallets and store public identifiers only.

# list active only augur accounts | python3 -m json.tool | head -n 120 # list all including paused augur accounts:all | python3 -m json.tool | head -n 220 # add an XRPL wallet augur add xrpl rYOUR_ADDRESS "My XRPL Wallet" mainnet | python3 -m json.tool # pause an account augur pause ACCOUNT_ID | python3 -m json.tool # resume an account augur resume ACCOUNT_ID | python3 -m json.tool # delete an account augur delete ACCOUNT_ID | python3 -m json.tool
Replace rYOUR_ADDRESS and ACCOUNT_ID. Use quotes around labels with spaces.

Snapshots

Pull latest activity for all active accounts and write to the local vault.

# run snapshot job augur snapshot
Vault path defaults to /var/www/augur/vault/sample_vault. Override with AUGUR_VAULT_PATH.

Monthly summaries

Generate a monthly summary for a given YYYY-MM.

# generate month augur monthly 2026-02 # example view output path # vault/reports/monthly/YYYY-MM/summary.json

Export public summary

Export the monthly summary to a public JSON location for the site or other consumers.

cd /var/www/augur || exit 1 chmod +x scripts/export_public.sh # export a month to public_data/summary.json MONTH="2026-02" bash scripts/export_public.sh "$MONTH" # inspect ls -la public_data cat public_data/summary.json | head -n 60

Common troubleshooting

  • API says up but curl fails: verify port and process, then retry health
  • EADDRINUSE: stop background API before starting foreground
  • Stale CLI: re-run installer
  • Wrong vault: set AUGUR_VAULT_PATH
# port check ss -ltnp | grep 8787 || echo "8787 not listening" # log tail ls -la /tmp/augur_api.log || true tail -n 120 /tmp/augur_api.log || true # stop any listener on 8787 via CLI augur api:stop # start again augur api:bg curl -sS http://127.0.0.1:8787/health ; echo
