AUGUR operator runbook

Use this to install the CLI, run the API, add wallets, generate snapshots, and export monthly summaries.

read-only public data only no wallet connection no keys no custody
Default local API: http://127.0.0.1:8787
Contact: augurintel@gmail.com

Install the AUGUR CLI

Run this inside the repo on your server.

cd /var/www/augur chmod +x scripts/install_augur_cli.sh bash scripts/install_augur_cli.sh command -v augur augur status
If you moved machines or paths, confirm the wrapper points to: /var/www/augur/cli/augur

Start and stop the API

# start in background augur api:bg # confirm healthy curl -sS http://127.0.0.1:8787/health ; echo curl -sS http://127.0.0.1:8787/api/health ; echo # tail logs augur api:logs # stop augur api:stop
If you see EADDRINUSE, something is already bound to 8787. Use augur api:stop, then retry.

Add and list wallets

Examples for XRPL. Replace rYOUR_ADDRESS and label.

# list active augur accounts | python3 -m json.tool # list all (including paused) augur accounts:all | python3 -m json.tool # add XRPL wallet augur add xrpl rYOUR_ADDRESS "My XRPL Wallet" mainnet | python3 -m json.tool
If JSON parsing fails, you got a non-JSON response. Run the command without python3 -m json.tool to see the raw output.

Snapshot and monthly summary

# pull fresh chain data into vault augur snapshot # generate month summary augur monthly YYYY-MM
Use YYYY-MM like 2026-02

Vault path override

Default vault is /var/www/augur/vault/sample_vault. Override for production vaults.

export AUGUR_VAULT_PATH="/var/www/augur/vault/YOUR_VAULT" augur status

Troubleshooting

  • API not healthy yet: check /tmp/augur_api.log and wait for the listen line, then re-test /health
  • Port not listening: run augur api:bg, then ss -ltnp | grep 8787
  • JSONDecodeError: remove the python pipe and inspect raw output, fix the underlying command
  • EADDRINUSE: run augur api:stop, confirm nothing listening, then start again
tail -n 200 /tmp/augur_api.log ss -ltnp | grep 8787 || echo "8787 not listening"
