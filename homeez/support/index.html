HOMEEZ SUPPORT.

Questions about HOMEEZ? Get in touch or check the guidance below.

Public purchasing is not open yet. Free demo spins and connecting a wallet do not grant an NFT.

Contact support

Email HOMEEZ Support

For an order issue, include your order reference, transaction hash and a short description of what happened. Do not include wallet secrets.

Wallet connection

When connection is enabled, start from the Capsule Machine and use its Xaman QR code or open-in-Xaman link. Check the app name and request details before signing. A sign-in request should not ask you to send XRP.

If you cancel or the request expires, return to the page and try connecting again. Use the purchasing wallet when checking an existing order.

Payment still pending?

Do not pay twice to clear a pending status. Signing a request or returning from Xaman does not by itself confirm payment or delivery.

When order checks are available, use the existing order's status check. If you are unsure, email your order reference and transaction hash for review. Refunds are not automatic and require review and approval.

Waiting to claim?

When claiming is enabled and your order is ready, use its claim action and review the NFT acceptance request in Xaman. If a claim link expires or the status remains pending, check the existing order again or contact support. Do not make another purchase to resolve it.

A pending claim is not confirmed ownership. Wait for the delivery status to be verified.

How to claim

  1. Open Xaman.
  2. Tap the HOMEEZ request (Events → Requests).
  3. Approve the 0 XRP NFT offer (small network fee applies).
  4. Come back to My HOMEEZ.

No request? Open the Capsule Machine, tap Check My Order, connect the wallet you paid with, then tap Claim NFT.
Sent to a different page? Go to My HOMEEZ and reconnect. Status shows Delivered only after the XRPL confirms it.

Keep your wallet secrets private

Never share a seed phrase, private key, wallet password, PIN or recovery code. HOMEEZ support does not need them.

Do not send XRP to someone claiming it is needed to unlock support or release a pending order.
