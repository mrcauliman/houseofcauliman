复习钱包基础 · 跳到引导式工作表 · 常见问题 · 要留下什么

你会用到的词

NFT
一枚单独标识的账本代币。两张相同的图片可以属于不同的 NFT。
NFTokenID
要在正确的网络上逐字比较的代币标识。
分类码（taxon）
由发行方选定、用来给相关 NFT 分组的值，不是稀缺性证书。
URI 与元数据
URI 是数据位置或标识。元数据描述一件物品，通常还包括一个单独的图片位置。
铸造（mint）、销毁（burn）与挂单（offer）
铸造（mint）创建 NFT；销毁（burn）销毁它的账本代币；挂单（offer）提议一次交换，并且可以一直不被接受。

检查这条记录

记下网络、NFTokenID、发行方、当前所有者和分类码（taxon）。分类码把同一发行方的相关 NFT 归为一组；它不是稀有度的证明，也不是收藏已完成的承诺。所有权和铸造是不同的角色。

检查铸造（mint）时的选择

NFTokenMint 会设置重要的标志（flags）。Transferable 允许普通持有人之间转让；没有它时，与发行方相关的转让有特别限制。Burnable 把销毁（burn）权限给予发行方或其授权方；所有者可以销毁自己的 NFT。可变的 NFT 可以由发行方或经授权的铸造者通过 NFTokenModify 更新其 URI。不要假设每一枚 NFT 的元数据指针都是固定的。

把内容分开读

URI 指向或包含元数据；它不保证图片一直在线，不保证远程内容永不改变，也不保证发行方拥有版权。请检查存储计划和任何许可。一张相符的图片可以被复制到另一枚无关的 NFT 上。

顺着挂单（offer）的生命周期

出售通常使用 NFT 挂单（offer）及其接受。创建挂单并不是已完成的付款或交付。接受之前，请核对确切的 NFT、支付资产、金额、目的地限制、到期时间和发行方转让费。NFT 转让费的单位是 0.001%；例如 1,000 表示 1%，而不是 1,000 XRP。是否适用取决于该次转让。事后确认已验证的结果和所有权。

检查俱乐部会员收藏品

俱乐部现在提议一枚可选的纪念 NFT。它和积分是分开的。使用这条虚构记录：网络 Testnet；NFT 身份 Record N；发行方 Issuer A；所有者 Member B；可转让：是；可销毁（burn）：是；可变：是；转让费字段 1,000；URI 为一个 HTTPS 元数据页面。这些是描述字段，不是交易 JSON。

  1. 检查表从网络、完整的 NFT 身份、发行方和观察到的当前所有者开始。如果你检查的是真实的公开记录，请记下观察发生的时间和所在的已验证账本。卖家的截图只是一条线索，不是所有权检查。
  2. 把标志（flags）翻译成普通问题。持有人可以互相转让它吗？发行方或其授权方可以销毁（burn）它吗？它的 URI 可以更改吗？每一项记下是、否或未知。不要从市场描述推断一项权限。
  3. 顺着媒体链路：从 NFT 到元数据，再到图片。记下谁运营每一个位置，谁保持副本可用。即便是按内容寻址的标识，也需要有人保留并提供这些内容；单靠一个固定标识并不是可用性服务。
  4. 阅读单独的许可和会员条款。这件收藏品给予的是作品权利、场地入场、会员身份，还是仅仅一件纪念品？只写下实际授予的权利。场地仍然可以要求它自己的入场程序。
  5. 检查一笔虚构的拟议出售：NFT Record N，价格 20 XRP，受限接收方 Member C，并写明了到期时间。NFT 转让费字段 1,000 表示 1%。在一笔适用的 20 XRP 出售上，那是 0.2 XRP；请检查实际的出售方式和结算记账，不要假设每一个显示价格都是卖家净得。
  6. 标出这个顺序：挂单（offer）已提议；挂单已在账本上创建；挂单在已验证账本上被成功接受；之后再检查所有者。已过期、已取消或仍开放的挂单不是已完成的出售。把挂单身份和 NFT 身份分开保留。
已做好的决定

俱乐部把这件收藏品称为永久的，但示例明确允许更改 URI，以及经发行方授权的销毁（burn）。把这个说法改写成：一件可转让的收藏品，发行方控制已披露，内容托管在外部。保存计划和许可要分开写明。更清楚的承诺，比一枚“永久”徽章更有用。

可选：把工作表接到一条公开记录上

在只读账本浏览器（explorer）上，选择目标网络并搜索完整的 NFTokenID。找到当前所有者、发行方、分类码（taxon）、标志（flags）和 URI。如果浏览器没有解释标志，就用所链接的交易参考来解码。如果有观察时间和账本，请记下来。把远程元数据链接当作不可信的内容；不要为了显示一张图片而去签署请求。

官方 XRPL 账本浏览器目录 · 网络修正案（amendment）参考。仅仅阅读一条公开记录并不需要钱包。不要在这些练习里输入私人或个人资料。

常见问题以及要检查什么

图片消失了

检查元数据和图片位置是否仍能打开。账本代币可以存在，同时内容托管失败。不要把钱包连到一个所谓的图片修复页面。

持有人之间的转让失败

检查当前所有权、转让权限、挂单（offer）身份、到期时间和目的地限制。不可转让的 NFT 有与发行方相关的特定转让规则；不要承诺不受限制的转售。

所有者不能更改 URI

所有权本身不是编辑权限。对于可变的 NFT，NFTokenModify 仅限于发行方或经授权的铸造者；网络修正案（amendment）和钱包支持也有关系。

继续之前要留下什么

在项目笔记里加一张 NFT 检查表：身份、所有者观察、权限、媒体链路、许可，以及拟议出售清单。向朋友解释，为什么图片、代币和会员承诺需要分开检查。

不签名，试着做

把这个例子做一遍

一条上架信息写着“永久收藏品”。该 NFT 是可变的，图片放在普通网站服务器上，卖家出示的是截图而不是 NFTokenID。哪些说法仍然未经证实？

对照你的推理

这张截图并不能标识这枚 NFT。取得它的网络和 NFTokenID，检查发行方和所有者，然后检查标志（flags）和 URI。可变的元数据和外部托管需要一份披露和保存计划。账本所有权不会自动转移版权，也不能证明图片永久可用。
